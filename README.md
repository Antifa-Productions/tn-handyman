### Installation

### Method 1: Using the Install Prompt (Automatic)

1. **Open the PWA** – Navigate to a PWA website in Chrome.
2. **Look for the install icon** – Check the address bar on the right side. When a PWA is installable, a **download or install icon** (usually a house or box icon) will appear.
3. **Click the install button** – Click the icon to trigger the install prompt.
4. **Confirm the installation** – A dialog box will appear asking you to confirm. Click **"Install"**.
5. **The PWA launches** – Chrome will open the installed app in a window without the browser UI, and a shortcut will be added to your desktop or app drawer.

### Method 2: Manual Installation via Menu

1. **Open the PWA** – Navigate to a PWA website in Chrome.
2. **Open the Chrome menu** – Click the three-dot menu icon in the top-right corner.
3. **Select "Install app"** – Look for this option in the dropdown menu (only appears for installable PWAs).
4. **Confirm the dialog** – Click **"Install"** in the confirmation prompt.
5. **Access your installed app** – The app will appear in your system's app list and taskbar.

### After Installation

- **Launch anytime** – Find the app in your system's app menu or search for it by name.
- **Standalone experience** – The PWA runs without browser tabs, address bar, or menus (unless configured otherwise).
- **Access via Chrome Apps** – You can also manage installed PWAs by typing `chrome://apps` in the address bar.
